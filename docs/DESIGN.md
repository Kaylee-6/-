# HOKKAIDO 2027 — Snow & Beyond · 产品与视觉设计方案

> 私人北海道冬季旅行助手。2027/2/12 – 2/19 · YVR → CTS → 小樽 → 札幌 → 二世古 → 留寿都 → 洞爷湖 → CTS → YVR

---

## 1. 产品定位

| 项目 | 说明 |
| --- | --- |
| 用户 | 本人（旅客 A）+ 同伴（旅客 B），可扩展到 4 人 |
| 使用场景 | 出发前：订票、核对、预算、待办。旅途中：每天打开看今日行程、导航、酒店信息、雪票、记账 |
| 设备 | 手机优先（iPhone 添加到主屏幕，离线可看），兼容桌面 |
| 核心原则 | **只展示用户提供或可核实的信息**。没有的订单号、姓名、电话保持空白；所有估算明确标注；候选方案不得显示为已购买 |

## 3. 状态体系（全站统一）

| 维度 | 取值 | 视觉 |
| --- | --- | --- |
| 预订状态 | **Confirmed** 已确认 · **Planned** 计划中 · **Optional** 可选 | 森林绿实心 · 海军蓝描边 · 金色虚线 |
| 付款状态 | 已付 · 扣款待确认 · 未付 · 估算 | 绿点 · 金点 · 灰点 · 斜纹 |
| 附加标签 | 待确认 / 未购买 / 待核实 / 估算 / 参考 | 小号文字标签 |

规则：
- 候选航班永远是 Planned + 未购买，直到用户「录入实际购买航班」。
- 雪票：Ikon Pass 不覆盖 Rusutsu（矩阵中禁止选择）；Epic Pass 在 Rusutsu 为「待核实」。
- 估算金额只进入「预估」，绝不进入「已付」。

## 4. 数据模型要点

- **单一数据源**：预订类费用（4 家酒店、租车、AC54 现金、已购去程）由对应模块实时派生到费用页，费用页不允许再手动录入同一笔，杜绝重复计算。
- **加币记账优先**：Ctrip 人民币订单使用用户提供的 CAD 账目（388.21、592.00），原币 RMB 同时显示；不按汇率重算。
- **CNY 默认汇率**：由用户两笔 Ctrip 订单推算（1,861.86 ÷ 388.21 ≈ 4.7960；2,838.65 ÷ 592 ≈ 4.7950，取 4.7955），标注来源。
- **JPY 汇率**：初始为空；首次联网时自动获取 ECB 参考汇率（Frankfurter API）并记录日期；也可手动输入。未设置时 JPY 估算项显示「待换算」且不计入合计。
- **积分**：Aeroplan 47,400 单独统计，不折算现金；OneKeyCash CAD 78.60 已体现在二世古现金 264.74 中，仅展示。
- **时间**：所有时刻以带时区偏移的 ISO 存储（JST +09:00 / PST −08:00），倒计时按绝对时间计算。
- **取消截止**：只存日期「前」；具体时刻与时区默认空白，用户按订单补填后 .ics 才生成精确时刻，否则生成全天事件 + 提前提醒。
- **持久化**：localStorage（带版本号），支持 JSON 导出 / 导入 / 恢复初始。

## 5. 视觉设计

**方向：Quiet Luxury × 日式极简 × 冬季旅行杂志。** 大量留白、细线分隔、克制的金色点缀，像一本放在温泉酒店床头的旅行刊物。

### 色彩

| Token | 浅色 | 深色（夜间） | 用途 |
| --- | --- | --- | --- |
| snow | #F6F5F1 | #0F1822 | 页面底色 |
| paper | #FFFFFF | #16222E | 卡片 |
| ice | #D7E7EC | #1F3444 | 次级底色、选中态 |
| navy | #20354A | #DCE6EC | 主文字、品牌 |
| forest | #596C60 | #8FA796 | Confirmed、完成 |
| gold | #C1A682 | #C9B08C | 强调、Optional、倒计时 |
| mist | #7D8B96 | #8D9AA5 | 次要文字 |
| line | #E3E1DA | #26394A | 分隔线 |

不使用樱花粉、卡通元素。深色模式为夜晚雪灯/滑雪后使用而设计，不是简单反色。

### 字体

- 西文展示：**Cormorant Garamond**（Light / Italic）— HOKKAIDO 2027、DAY 03、英文地名
- 界面西文：**Instrument Sans**（可变字重）
- 数据 / 机场代码：**IBM Plex Mono** — YVR · CTS · AC54 · JST，形似登机牌与机场标识
- 中文：系统字体（PingFang SC / Noto Sans SC / 微软雅黑），零额外下载
- 字体全部本地打包（@fontsource），离线可用

### 版式

- 手机单列，16px 侧边距；桌面 1180px 内容宽 + 左侧导航
- 卡片圆角 18px，仅关键对象用阴影；列表靠细线而不是卡片堆叠
- 数字统一 tabular-nums
- 日期写法：`2.16 TUE · 2月16日 周二`

### 插图

为避免使用来源/授权不明的照片，所有封面均为**原创矢量插画**（SVG，任意分辨率清晰、离线可用、零图片请求）：羊蹄山晨光、小樽运河雪灯、札幌电视塔夜景、二世古白桦粉雪、留寿都树林雪道、洞爷湖与中岛、各酒店意象。每张封面都可在编辑中替换为自己的照片 URL 或上传照片（本地压缩后保存）。

### 动效

- 页面切换：轻微上移 + 淡入（180ms）
- 底部抽屉表单：弹簧滑入
- Hero 细雪粒子（CSS，遵守 `prefers-reduced-motion`）
- 倒计时数字等宽、无闪烁
- 图表、Recharts 只在费用页按需加载（代码分割），首屏不加载

## 6. 技术方案

- React 19 + TypeScript + Vite 7
- Tailwind CSS v4（CSS 变量主题，支持深色）
- motion（Framer Motion）、lucide-react、Recharts
- 无路由库：轻量 hash 路由（离线 / 任意子路径部署都可用）
- vite-plugin-pwa：预缓存全部页面、字体、图标；离线可看所有订单与行程
- Vitest：预算合计（2,178.17）、不重复计算、汇率、ICS 生成等单元测试

## 7. 数据真实性清单

| 规则 | 实现 |
| --- | --- |
| 不编造订单号 / 姓名 / 电话 | 字段默认空白，显示「未填写」 |
| 候选航班不标记已购买 | 状态锁定 Planned·未购买，需手动录入实际航班 |
| 雪票均未购买 | 矩阵状态为「需购买 / 待确认 / 待核实」 |
| 不把估算当已付 | 估算只计入「预估」 |
| 地图链接真实 | Google Maps 官方 URL 格式 + 真实名称/地址 |
| 官网链接可核实 | 仅放经检索核实的官方域名；无法核实的不放 |
| 雪祭 | 札幌雪祭在抵达前已结束，不作为可参加活动 |
| 小樽雪灯之路 | 按用户信息 2/13 为最后一天；标注「以官方公布为准」 |
| 车程 | 均为「参考约」，标注「冬季以实时导航为准」 |
