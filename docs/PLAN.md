# 猫猫档案 · 规划设计 v0.1

> 状态：规划阶段，等你提供服务器和域名后开工。
> 可点击原型：`design/prototype.html`（里面的猫名、日期、数字全是示例）。

---

## 1. 目标

- **家里人共用的一个网站**：手机优先，能「添加到主屏幕」像 App 一样打开（PWA）。
- **记录要快**：铲屎、换水、喂饭，3 秒内点完。
- **到期自动提醒**：疫苗、驱虫、体检、饮水机滤芯、全换猫砂。
- **实时联网**：
  - 家里谁记了一笔，其他人手机上马上看到；
  - 每天联网，结合两只猫的年龄、爱好、最近记录和天气，生成专属养猫小贴士；
  - 显示 AI 用了多少 token、大概花了多少钱。
- **可爱**：圆润、粉嫩、有猫脸插画，但信息一眼看得清。

## 2. 研究结论：一份猫档案需要记什么

### 2.1 基本档案

| 字段 | 说明 |
|---|---|
| 名字 / 小名 / 头像 / 相册 | |
| 生日 | 不确定时勾选「估计生日」（领养、捡来的猫常见） |
| 到家纪念日 | 每年提醒，做成小彩蛋 |
| 性别 / 是否绝育 / 绝育日期 | 公猫泌尿问题风险更高，会影响提醒规则 |
| 品种 / 毛色 | |
| 芯片号 | 走失找回、办证用 |
| 饮食 | 主粮品牌、干湿比例、过敏/忌口 |
| 常去医院 / 主治医生 / 宠物保险 | |
| 性格标签 / 兴趣爱好 / 讨厌的东西 | 见 2.8 |

### 2.2 年龄

- 显示「X 岁 X 个月」，并自动算：
  - **人类年龄换算**（趣味用）：1 岁 ≈ 15，2 岁 ≈ 24，之后每年 +4。
  - **生命阶段**（AAHA/AAFP 2021 猫生命阶段指南）：幼猫 0–1 岁、青年 1–6 岁、成熟 7–10 岁、老年 10 岁以上。
- 生命阶段会影响：体检频率提醒、小贴士内容、饮食建议。

### 2.3 疫苗（默认模板，每一项都可以改，以兽医为准）

| 疫苗 | 幼猫 | 成年后 | 备注 |
|---|---|---|---|
| **猫三联 FVRCP**（猫瘟 + 鼻支 + 杯状病毒） | 6–8 周龄开始，每 3–4 周一针，打到 16 周龄以后 | 6 个月或 1 岁时加强一次，之后低风险室内猫每 3 年一次 | 核心疫苗。国内不少医院仍建议每年一次，网站里可以改间隔 |
| **狂犬疫苗** | 12–16 周龄首针 | 1 年后加强，之后按产品说明（1 年或 3 年）和当地规定 | 国内多数医院按每年一次；部分城市办证需要免疫证 |
| **猫白血病 FeLV** | AAHA 2020 把它列为 1 岁以下幼猫的核心疫苗 | 成年后看风险：会出门、家里常来新猫才建议 | 打之前一般先检测 |

每条疫苗记录保存：疫苗种类、品牌/产品、批号、第几针、接种日期、**下次到期日**、医院、医生、疫苗本照片、接种后反应。

两针疫苗之间至少间隔 2 周（AAHA 建议），系统录入时会提示。

### 2.4 驱虫

| 类型 | 常见频率（室内成年猫） | 记录 |
|---|---|---|
| 体内驱虫 | 每 3 个月 | 药名、剂量、当时体重、下次日期 |
| 体外驱虫 | 每月 | 同上 |

幼猫频率更高（约 6 周龄开始，每 2–4 周一次）。不出门的猫可以和兽医商量放宽。

### 2.5 体检、体重、就诊、用药

- **体检**：青年/成熟期每年 1 次；老年猫建议每半年 1 次。
- **体重**：建议每月称一次，同时记体况评分（BCS 1–9 分，5 分理想）。一个月掉秤 5% 以上就提醒。
- **就诊记录**：日期、原因、诊断、花费、化验单照片、复诊日期。
- **用药**：药名、剂量、频率、起止日期，按时提醒喂药。

### 2.6 猫砂盆（重点）

**为什么要记**：上厕所的次数和样子是泌尿问题、肾病、糖尿病最早能看到的信号。

**每次记录**：
- 谁（团子 / 年糕 / **不确定**：两只猫共用猫砂盆时经常分不清，所以必须有这个选项）
- 类型：小便 / 大便 / 都有
- 尿团大小：小 / 中 / 大（次数正常但尿团变大变多，也说明尿量变多）
- 大便状态：正常 / 偏软 / 拉稀 / 偏硬
- 异常：用力很久、在盆外、有血
- 时间、哪个猫砂盆、谁记的

**维护记录**：铲屎、全换猫砂、清洗猫砂盆。

**参考**：
- 猫砂盆数量 = 猫的数量 + 1，两只猫建议 3 个；
- 多猫家庭最好每天铲 2 次；
- 结团砂多猫家庭 1–2 周全换一次。

> **急症提醒**：公猫频繁进猫砂盆、使劲却尿不出或只有一点点，可能是尿道堵塞，24–48 小时内就可能危及生命。系统里一旦记录「用力 + 尿不出」，首页直接弹红色提醒：**马上去医院**。

### 2.7 饮水机

- **参考饮水量**：每公斤体重每天 40–60 ml（包括湿粮里的水；吃干粮的猫喝得更多）。长期超过 100 ml/kg/天 算偏多，要留意。
- **怎么记**：两只猫共用饮水机，分不清谁喝了多少，所以记**全家总量**：每次换水/加水时记加了多少 ml，系统按天算消耗。
  （想分开统计，只能靠能识别猫的智能设备，见 5.6。）
- **维护**：至少每周彻底清洗并换水一次；滤芯按说明书 1–3 个月换一次。系统显示「滤芯已用 X/30 天」进度条。

### 2.8 兴趣爱好 & 性格

- 最爱的玩具、最爱的零食、最爱待的地方、玩耍风格（追逐型 / 伏击型 / 抱踢型）
- 讨厌的东西（吹风机、剪指甲……）
- 性格标签（干饭王、社牛、胆小……）
- 「第一次」时刻相册：第一次到家、第一次踩奶……

这些会喂给 AI，生成「专门给团子的」玩耍和互动建议。

### 2.9 异常提醒规则（只提醒，不诊断）

| 等级 | 条件 | 提示 |
|---|---|---|
| 🔴 红 | 记录了「用力 + 尿不出」；大便有血 | 马上就医 |
| 🟡 黄 | 某只猫 7 天平均如厕次数比前 2 周高 50% 以上 | 留意观察，持续就问兽医 |
| 🟡 黄 | 家庭饮水量连续 3 天高于参考上限 | 同上 |
| 🟡 黄 | 连续 2 天拉稀 | 同上 |
| 🟡 黄 | 一个月体重变化超过 5% | 同上 |
| 🔵 蓝 | 超过 X 小时没有某只猫的小便记录 | 「可能只是没记，有空看看猫砂盆」 |

阈值都可以在设置里改。

## 3. 页面设计（底部 5 个标签 + 右上角设置）

| 页面 | 内容 |
|---|---|
| **今天** | 两只猫的卡片（头像、年龄、人类年龄、生命阶段、今日如厕次数）；三个大按钮：猫砂盆 / 饮水机 / 喂饭；到期提醒；今日小贴士；家庭动态（实时） |
| **记录** | 本周如厕次数图（两只猫分色）；饮水量图（带参考区间）；健康检查结果；猫砂和饮水机维护进度 |
| **健康** | 疫苗（已完成 / 快到期 / 已逾期）、驱虫、体检就诊、用药；拍疫苗本照片自动识别 |
| **猫咪** | 档案、兴趣爱好、性格、体重曲线、按爱好推荐的玩法、相册 |
| **贴士** | 今天的专属小贴士、按话题筛选的精选贴士库、**AI token 用量面板** |
| 设置（右上角齿轮） | 家庭成员、提醒发到哪、猫砂盆和饮水机设备、AI 开关和预算 |

交互细节（原型 v0.2 已实现）：
- **一键记录**：猫咪卡片上的「小便 ＋」「大便 ＋」点一下就记一次；有异常、要补细节才打开猫砂盆表单。
- **撤销**：每次记录后提示条上有「撤销」，5 秒内可以撤回。
- **补记**：表单里可以选「刚刚 / 15 分钟前 / 半小时前 / 1 小时前」。
- **上次小便时间**：每只猫卡片上都显示，比次数更能早点发现尿不出的问题。选了「尿不出」的那次不算小便。
- **防误记**：「异常」和「时间」每次记完都会重置，不会带到下一次。
- **字体**：中文正文用手机自带字体，标题的可爱字体只下载用到的字（原型里 4 个字体文件、58 KB，原来是 27 个文件、1.16 MB）。正式版把裁剪后的字体文件放在自己服务器上。

视觉方向：草莓牛奶粉 + 薄荷绿 + 奶油黄，圆角、手绘风猫脸；两只猫各自固定一个颜色，图表、标签都用同一个颜色区分。支持深色模式（晚上铲屎不刺眼）。

## 4. 实时联网 & AI

### 4.1 家庭实时同步
任何人记一笔，其他人打开的页面马上更新（PocketBase 自带实时订阅），首页「家庭动态」显示「爸爸 · 刚刚 · 换了饮水机的水」。

### 4.2 AI 每日小贴士
- **每天生成一次**（不是每次打开都调用，省 token），缓存起来全家看同一份。
- **输入**：两只猫的年龄/生命阶段/性别/爱好、最近 7 天记录摘要、即将到期的项目、当地天气（季节、气温、湿度）。
- **输出**：2–3 条短贴士 + 1 条针对爱好的玩耍建议。
- **安全**：只基于精选的权威资料库改写（AAHA/AAFP、WSAVA、康奈尔猫健康中心、International Cat Care），每条标注「AI 生成，仅供参考，不能代替兽医」。
- **其他 AI 功能（可选）**：每周健康小结；拍疫苗本照片自动识别成记录；「问问猫博士」问答。

### 4.3 Token 用量面板（你刚提的需求）
每次调用 AI 都记一条：时间、功能、模型、输入 token、输出 token、缓存 token、折算费用。

面板显示：
- 今天 / 本月用了多少 token、约多少钱
- 按功能拆分（小贴士、周报、疫苗本识别、问答）
- 最近 14 天每日用量柱状图
- 每月预算（比如 20 万 token），用到 80% 提醒，用完自动暂停 AI 功能
- 单价写在设置里，可以随时改

**预估用量**：每日小贴士约 2k token/天，加上每周小结，一个月大约 6–10 万 token，很省。

### 4.4 其他联网数据
- 天气：Open-Meteo（免费，不用申请 key）或和风天气（国内更准）。
- 季节提醒：比如现在 10 月，开暖气后空气干，提醒多放一个水碗。

### 4.5 ⚠️ 服务器位置会影响 AI
**Claude API 在中国大陆不能直接用。** 如果服务器在大陆，有两个办法：
1. 服务器放香港或海外（还能免掉 ICP 备案）；
2. AI 部分换国内模型。

代码里 AI 接口会做成可替换的。

## 5. 技术方案

| 部分 | 选择 | 理由 |
|---|---|---|
| 前端 | React + Vite + TypeScript，做成 PWA | 手机上能装到主屏幕，离线也能先记、联网再同步 |
| 后端 | **PocketBase**（单个程序 + SQLite） | 自带登录、实时订阅、文件存储（照片、疫苗本）、管理后台、定时任务；一个家庭用绰绰有余 |
| 部署 | Docker Compose + Caddy | Caddy 自动申请 HTTPS 证书 |
| 备份 | PocketBase 自带备份，每天 1 次，可同步到对象存储 | 猫的资料丢不得 |
| 提醒推送 | Web Push（iOS 16.4+ 添加到主屏幕后可用）；可选 Bark（iPhone）、企业微信机器人、邮件 | 国内家庭大概率想要微信，需要你选 |

### 5.6 让记录更快的小装置
- **NFC 贴纸 / 二维码**：贴在猫砂盆和饮水机上，手机一碰就打开对应的记录页，点一下就记好。
- **iPhone 快捷指令 / 安卓桌面小组件**：一键记一次铲屎。
- **智能设备（后期，可选）**：如果用小佩（PETKIT）猫砂盆/饮水机，社区有 Home Assistant 集成可以读取如厕和饮水数据。这些是非官方逆向的，固件更新后可能失效，所以只当「加分项」。

## 6. 数据结构（PocketBase 集合）

| 集合 | 主要字段 |
|---|---|
| `users` | 家庭成员：名字、头像、通知方式 |
| `cats` | 2.1 里的全部字段 + 颜色主题 |
| `vaccinations` | cat、种类、产品、批号、第几针、日期、下次到期、医院、照片、反应 |
| `dewormings` | cat、体内/体外、药名、剂量、体重、日期、下次到期 |
| `vet_visits` | cat、日期、原因、诊断、花费、附件、复诊日期 |
| `medications` | cat、药名、剂量、频率、起止 |
| `weights` | cat、日期、体重 kg、BCS |
| `litter_events` | cat（可为空 = 不确定）、box、类型、大小、大便状态、异常标记、时间、记录人、来源（手动/NFC/设备） |
| `litter_maintenance` | box、动作（铲屎/全换/清洗）、时间、记录人 |
| `water_events` | device、动作（换水/加水/清洗/换滤芯）、ml、时间、记录人 |
| `feedings` | cat、类型（干粮/湿粮/零食）、克数、时间 |
| `devices` | 猫砂盆 / 饮水机：名字、位置、型号、维护周期 |
| `reminders` | 自动从「下次到期」和设备维护周期生成，也可以手动加 |
| `moments` | 照片、文字、标签（第一次、爱好……） |
| `tips` | 内容、来源、AI/精选、日期、针对哪只猫、点赞 |
| `ai_usage` | 时间、功能、模型、输入/输出/缓存 token、费用 |
| `settings` | 阈值、预算、单价、提醒偏好 |

## 7. 分期

| 阶段 | 内容 |
|---|---|
| **P0 能用** | 登录、两只猫档案 + 年龄、疫苗/驱虫 + 到期提醒、铲屎/饮水机/喂饭快速记录、首页、实时同步、PWA |
| **P1 好用** | 图表、异常提醒、体重、就诊用药、相册、兴趣爱好页、推送通知、NFC/二维码 |
| **P2 联网聪明** | AI 每日小贴士、token 用量面板、天气、疫苗本拍照识别、每周小结 |
| **P3 加分** | 智能设备接入、导出「就诊用健康报告」PDF 给兽医看 |

## 8. 需要你提供

1. **两只猫**：名字、生日（或大概年龄）、性别、是否绝育、品种/毛色、照片各几张。
2. **疫苗本 / 病历**：拍照发我，我帮你整理成第一批记录。
3. **兴趣爱好和性格**：随便说，越具体越好玩。
4. **服务器**：在中国大陆还是境外？系统（Ubuntu？）、配置；**域名**（大陆服务器需要 ICP 备案）。
5. **家里谁用**：几个人，各自叫什么（妈妈/爸爸/名字）。
6. **提醒想发到哪**：手机推送 / 微信（企业微信机器人）/ Bark / 邮件。
7. **设备**：现在用的猫砂盆、饮水机是什么牌子？有没有智能款？几个猫砂盆？
8. **AI**：要不要开 AI 功能；每月 token 预算大概多少。
