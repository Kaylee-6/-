# HOKKAIDO 2027 — Snow & Beyond

北海道冬季旅行的私人助手网页（PWA）。2027/2/12 – 2/19 · 温哥华 YVR ⇄ 札幌新千岁 CTS · 小樽 → 札幌 → 二世古 → 留寿都 → 洞爷湖。

手机优先，桌面兼容；可添加到 iPhone 主屏幕，订单与行程离线可看；所有修改自动保存在本机浏览器，可导出 / 导入 JSON 备份。

产品信息架构与视觉方案见 [`docs/DESIGN.md`](docs/DESIGN.md)。

## 功能

| 页面 | 内容 |
| --- | --- |
| 首页 | 雪山 Hero、实时出发倒计时、路线简图、今日行程、下一项待办、准备进度、费用概览、关键时间（取消截止 / 取还车 / AC54） |
| 行程 | Day 0–7 时间线；Confirmed / Planned / Optional 三态；新增、编辑、删除（可撤销）、改时间自动排序、上下移动、移到其他日；候选目的地一键加入；当日备注；当晚酒店、滑雪、驾驶路线 |
| 住宿 | 4 家酒店完整卡片：入住退房、房型、早餐、平台、原币 + 加币账目、付款状态、取消期限倒计时、地址、电话、停车、提醒、地图 / 导航 / 官网；可编辑订单号等 |
| 交通 | 去程候选 A / B 对比（未购买）、录入实际购买航班；AC54 登机牌式卡片（现金与积分分开）；租车订单、取还车倒计时、冬季配置 / 保险 / Amex 条件勾选、人数与行李容量检查；每段驾驶路线导航 |
| 滑雪 | 3 个滑雪日、出发 / 回酒店时间、雪票覆盖矩阵（Ikon 不能设为覆盖 Rusutsu）、雪场介绍与雪况链接、雪票预算（估算）、装备清单 |
| 目的地 | 小樽 / 札幌 / 二世古 / 留寿都 / 洞爷湖杂志式介绍，景点地图与「加入日程」 |
| 费用 | 已确认基础总金额 CAD 2,178.17 + 47,400 Aeroplan；已付 / 扣款待确认 / 估算分开；Donut 图与付款进度；预算项可编辑；旅途支出记录；CAD / JPY / CNY 切换 |
| 清单 | 分组待办、优先级与截止日；酒店取消截止自动生成 .ics 日历提醒；关键行程 .ics |
| 设置 | 旅客 1–6 人（默认 2 人）、汇率（手动或 ECB 参考汇率）、深浅色、JSON 备份、主屏幕安装说明、数据来源 |

## 运行

需要 Node.js 20+。

```bash
npm install
npm run dev        # 本地开发 http://localhost:5173
npm test           # 单元测试（预算合计、不重复计算、汇率、日历提醒等）
npm run build      # 类型检查 + 生产构建，输出到 dist/
npm run preview    # 预览生产构建（含离线 Service Worker）
```

## 部署

`dist/` 是纯静态文件，使用相对路径，可以放在任意静态托管的任意子路径下：

- **GitHub Pages**：仓库 Settings → Pages → Source 选 *GitHub Actions*，然后在 Actions 里手动运行 *Deploy to GitHub Pages*。
- **Netlify / Vercel / Cloudflare Pages**：构建命令 `npm run build`，发布目录 `dist`。

部署后用 iPhone Safari 打开 → 分享 → 「添加到主屏幕」。

## 数据说明

- 所有订单数据来自行程资料；未提供的订单号、乘客姓名、手机号保持空白，可在页面中补填。
- 候选航班、雪票、油费、高速、停车等均标为估算，绝不计入「已付」。
- 札幌 STREAM 与 Windsor 的人民币订单使用用户提供的加币账目（CAD 388.21、CAD 592.00），不随汇率变化；两家的扣款状态为「待确认」。
- 二世古 Hotel Kanronomori 的 OneKeyCash CAD 78.60 已体现在现金实付 CAD 264.74 中，不再重复扣除。
- CNY 默认汇率由两笔 Ctrip 订单推算（≈ 4.7955）；JPY 汇率首次联网时从 ECB 参考汇率获取，也可手动输入，页面会标明来源与日期。
- 取消截止只按订单上的日期「前」记录；具体时刻与时区默认空白，补填后日历提醒才生成精确时刻。
- 官网、电话为检索核实的公开信息；地图使用 Google Maps 官方 URL 格式；车程为参考值，冬季以实时导航为准。
- 封面为原创矢量插画（离线可用），不代表酒店或景点实景，每张都可以换成自己的照片。
